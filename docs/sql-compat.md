# SQL 兼容性说明

Flux SQL 以 ANSI SQL 为基线，面向 Spark SQL 方言提供兼容。与 Spark 方言的差异（未支持 / 语义偏差 / 扩展）随版本显式维护于本文件，每次发布核对一次（[架构与代码维护文档](05-架构与代码维护文档.md) §5.3 发布 runbook、[代码规范与开发指南](06-代码规范与开发指南.md) §5.5）。

- 完整函数目录与 SQL 文法：见[详细设计说明书](04-详细设计说明书.md)。
- 需求基线：SRS FR-QL 系列（[01-软件需求规格说明书](01-软件需求规格说明书.md)）。
